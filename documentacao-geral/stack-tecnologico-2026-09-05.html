Sistema ONG Animal

Stack Tecnológico

Ferramentas, frameworks e versões utilizadas na construção do sistema. Documento vivo — atualizado à medida que o projeto evolui.

Última atualização: 05 de setembro de 2026

Backend

API REST em Java com Spring Boot, responsável pelas regras de negócio e persistência dos dados.

Linguagem & Build

3

Java

17

Linguagem principal do backend. Versão LTS, base para todo o código da aplicação.

Apache Maven

3.9.11

Gerenciador de build e dependências do projeto (executado via Maven Wrapper).

Lombok

gerenciado pelo Spring Boot

Gera automaticamente getters, setters, builders e outros métodos repetitivos das entidades via anotações.

Framework & Backend

5

Spring Boot

3.5.13

Framework principal da aplicação. Fornece o servidor web embutido, injeção de dependências e configuração automática.

spring-boot-starter-parent

Spring Web

via Boot

Suporte a construção de APIs REST — controllers, serialização JSON e tratamento de requisições HTTP.

Spring Data JPA

via Boot

Camada de persistência: mapeia entidades Java para tabelas do banco e fornece repositórios prontos para uso.

Spring Validation

via Boot

Validação declarativa de dados de entrada (Bean Validation), usada nos DTOs e entidades da API.

Spring Boot DevTools

via Boot

Acelera o desenvolvimento com reinicialização automática da aplicação ao detectar mudanças no código.

Banco de Dados

3

PostgreSQL

driver via Boot

Banco de dados relacional utilizado para persistir os dados do sistema (animais, adotantes, espécies, raças).

Flyway

11.0.0

Controla o versionamento do esquema do banco através de migrações SQL sequenciais, aplicadas automaticamente ao iniciar a aplicação.

Hibernate

via Spring Data JPA

Implementação de JPA usada por baixo dos panos para converter objetos Java em comandos SQL.

Serialização & Outros

1

Jackson (XML)

via Boot

Biblioteca de serialização/desserialização; o módulo XML permite que a API também trabalhe com esse formato além de JSON.

Testes

3

Spring Boot Starter Test

via Boot

Conjunto de bibliotecas de teste (JUnit 5, Mockito, AssertJ) usado para os testes unitários e de integração da aplicação.

REST Assured

5.5.1

Biblioteca para testar a API REST de fora para dentro, fazendo requisições HTTP reais e validando as respostas (status, corpo, cabeçalhos) nos testes de integração.

Maven Failsafe Plugin

via Boot

Executa os testes de integração (classes terminadas em "IT") em uma fase separada dos testes unitários, contra o banco de dados real.

Frontend

Aplicação web em Angular, responsável pela interface usada para gerenciar animais, adotantes e raças.

Linguagem & Build

4

TypeScript

5.9.2

Linguagem principal do frontend — adiciona tipagem estática ao JavaScript, ajudando a evitar erros antes mesmo de rodar o código.

Angular CLI

21.2.13

Ferramenta de linha de comando usada para criar, rodar e compilar o projeto Angular.

@angular/build

21.2.13

Sistema de build oficial do Angular, baseado em Vite/esbuild — compila e otimiza a aplicação para desenvolvimento e produção.

npm

11.11.0

Gerenciador de pacotes e dependências do projeto (versão fixada via campo packageManager).

Framework & UI

4

Angular

21.2

Framework principal da aplicação. Usado no estilo "standalone" (sem NgModules), com componentes, rotas e injeção de dependências.

Angular Material

21.2.13

Biblioteca de componentes visuais prontos (tabelas, formulários, diálogos, ícones) seguindo o padrão de design Material.

Angular CDK

21.2.13

Conjunto de ferramentas de apoio usadas por baixo dos panos pelo Angular Material (comportamentos de acessibilidade, sobreposição de telas, etc.).

RxJS

7.8

Biblioteca para lidar com eventos e dados assíncronos (ex: respostas de requisições HTTP) através de fluxos observáveis.

Testes & Qualidade

2

Vitest

4.0.8

Executor de testes automatizados do frontend (substitui o Karma/Jasmine padrão do Angular), integrado via @angular/build:unit-test.

Prettier

3.8.1

Formatador de código automático, garantindo um estilo consistente em todo o projeto.

Versões extraídas de pom.xml e .mvn/wrapper/maven-wrapper.properties do repositório sistema-ong-animal (backend), e de package.json do repositório sistema-ong-animal-frontend (frontend).
